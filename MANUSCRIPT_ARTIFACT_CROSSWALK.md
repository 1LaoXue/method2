The formulas and rounding rules for `micro_accuracy` and `difficulty_balanced_accuracy` are defined once in `configs/metrics.json`. Each resolved configuration embeds exactly one active memory-build configuration: 225 main-protocol questions for ordinary experiments or 224 episode-disjoint questions for the episode-disjoint evaluation. Result uniqueness additionally includes condition, pass, and sensitivity-setting identifiers, preventing oracle passes and parameter settings from overwriting one another.

The appendix expression `N^{-1} sum_i I(a_i=y_i)` is the definition of `micro_accuracy`. It does not define the values in Tables 4, 6, or 7; those tables use the equal-stratum formula `(Acc_low + Acc_medium + Acc_high)/3` and the table-specific precision declared in `configs/metrics.json`.
